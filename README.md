# PROA: Planeación regenerativa de operaciones y abastecimiento

Trabajo final para la materia **Futuros Sustentables** de la Universidad Iberoamericana.

## Propuesta

PROA significa **Protocolo Regenerativo para Operaciones y Abastecimiento**. Es una propuesta académica para incorporar límites socioambientales al proceso de **Sales & Operations Planning (S&OP), o Planeación de Ventas y Operaciones**. La regla principal es la **doble viabilidad**: ningún escenario se aprueba si no cumple, al mismo tiempo, criterios operativos y socioambientales.

El sitio incluye:

- diagnóstico del problema;
- proceso PROA en cinco etapas;
- tablero mínimo de indicadores;
- comparador interactivo de escenarios;
- piloto de implementación de 90 días;
- fundamento conceptual y referencias del curso;
- modo exposición en pantalla completa.

## Abrir localmente

No requiere instalación ni proceso de compilación. Abre `index.html` en un navegador o ejecuta un servidor estático:

```bash
python3 -m http.server 8080
```

Después visita `http://localhost:8080`.

## Publicar en Vercel

El proyecto es un sitio estático. En Vercel, importa el repositorio y conserva la configuración automática. No se requiere comando de compilación y el directorio raíz contiene `index.html`.

## Alcance

El simulador es demostrativo. Sus ponderaciones y umbrales no representan un estándar técnico; una implementación real requiere calibración por producto, territorio, regulación y partes afectadas.
